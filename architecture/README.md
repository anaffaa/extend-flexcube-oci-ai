# Architecture diagrams

| File | What it shows |
|---|---|
| `logical-overview.png`, `logical-overview.drawio` | Logical view: FLEXCUBE source patterns, shared foundation, use-case modules, serving layer, agents and channels |
| `physical-architecture.png`, `physical-architecture.drawio` | Physical view: bank data center, Oracle Database@Azure, OCI region with the solution VCN, an existing FLEXCUBE VCN, Oracle AI Data Platform and supporting services |
| `build_*_diagram.py` | Scripts that generate the drawio files with the Oracle OCI Architecture Diagram Toolkit icons |

The `.drawio` files open in draw.io or diagrams.net and stay editable. Mermaid versions are embedded in the
[reference architecture](../docs/reference-architecture.md).
